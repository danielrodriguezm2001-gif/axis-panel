# datos/ — fuentes para el Analista SEO/Performance

⚠️ Esta carpeta está en `.gitignore`: los exports contienen datos personales y **no se suben al repositorio**.

Deja aquí cada lunes, antes de lanzar el flujo, lo que tengas (no hace falta todo; el analista trabaja con lo que haya y te dice qué falta):

| Archivo sugerido | De dónde sale | Para qué |
|---|---|---|
| `aimharder_pagos_finalizados.csv` / `aimharder_pagos_pendientes.csv` | AimHarder → pagos (los mismos que usas para el plan financiero) | Essentials vendidos, altas en Axis Club |
| `aimharder_clientes.csv` | AimHarder → clientes (altas/bajas) | Embudo, retención, reactivación |
| `contactos.csv` | Hoja de contactos (fecha, origen, estado: nuevo / valoración agendada / cliente / no interesado) | Contactos cualificados por canal |
| `instagram.csv` | Meta Business Suite → Estadísticas → exportar | Alcance, guardados, mensajes, seguidores |
| `google_business.csv` o captura `.png` | Google Business Profile → Rendimiento | Llamadas, rutas, búsquedas, reseñas |
| `meta_ads.csv` / `google_ads.csv` | Administrador de anuncios → exportar | Inversión, contactos, coste por Essentials |
| `ga4.csv` / `search_console.csv` | **Pendientes de instalar** | Tráfico web, consultas de búsqueda |

Nombres de archivo libres: si añades una fecha (`instagram_2026-10-12.csv`) mejor.
